El login es el proceso mediante el cual un usuario se identifica en una aplicación utilizando sus credenciales, como el correo electrónico y la contraseña. 
Esto permite verificar su identidad antes de acceder al sistema.

Algunas rutas deben estar protegidas porque contienen información privada o funciones que solo pueden utilizar usuarios autorizados. 
De esta manera, se evita el acceso no autorizado y se protege la integridad de la plataforma. Además, se garantiza que cada usuario solo pueda realizar 
las acciones correspondientes a su rol.
 
Tampoco se deben exponer públicamente datos sensibles como contraseñas, documentos de identidad, direcciones, teléfonos, tokens o claves de acceso. 
Proteger esta información ayuda a preservar la privacidad y la seguridad de los usuarios. Así, la plataforma genera mayor confianza y ofrece un 
entorno más seguro para toda la comunidad.
